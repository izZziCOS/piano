      Sync with GitHub

      Keep your progress (note statistics, practice calendar, speed tests, stars and finished chapters) in a private gist on your GitHub account, so it follows you to other computers and browsers. Settings like volume stay on each device.

      1. Create a GitHub token with only the gist permission (the link ticks it for you). Set it to expire in 30 to 90 days; when it does, create a new one and paste it in again.
      2. Paste it here and connect. Do the same on your other devices with the same token.

      The token is stored only in this browser and is sent only to GitHub. If this site is hosted at a shared github.io address, the owner’s other sites there could read it. That’s why it should have no permission except gists, and a short expiry.

      How to play

      • Mouse or touch: click the keys below. Drag across them to glide.
      • Computer keyboard: A S D F G H J K L ; are the white keys, and W E T Y U O P are the black keys. Z and X move down or up an octave. Hold Space for the sustain pedal.
      • MIDI keyboard: plug it in and press Connect MIDI below. Works in Chrome, Edge and Firefox (Firefox asks you to allow it first), but not in Safari.
      • Middle C (C4) has a small dot under it, so you can always find your place.

      Add your own piece

      Write the notes in the same simple format as the built-in pieces, or import a MusicXML file exported from MuseScore, Finale, Sibelius or Dorico. Your pieces are saved in this browser, and synced if sync is on.

      How to write notes
      C4 F#4 Bb3A note: letter, then # or b, then octave. Middle C is C4.
      G4:2 E4:0.5Length in beats: 4, 3, 2, 1.5, 1 (the default), 0.75, 0.5 or 0.25.
      R:1A rest.
      C3+E3+G3:4A chord.
      E4@3 C3+E3+G3@5+3+1Fingering (1 is the thumb).
      C4:2~ C4:1A tie: the first note is held into the next one. Use it for notes that cross a bar line.
      !p !mf !fA dynamic for the notes that follow (pp, p, mp, mf, f, ff).
      |A bar line. Optional: bars are worked out from the time signature.
      Keys start at C4
